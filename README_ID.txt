UNTUNGIN - VERSI AWAL ANDROID-FRIENDLY

ISI:
- index.html: tampilan aplikasi
- style.css: desain hitam emas
- app.js: navigasi dan penghitung kunjungan lokal
- manifest.json + sw.js: dukungan instalasi PWA/offline

CARA MENCOBA DI HP ANDROID:
1. Ekstrak ZIP ini menggunakan aplikasi Files/ZArchiver.
2. Untuk tes cepat, buka index.html di browser. Beberapa fitur instalasi/offline memerlukan hosting HTTPS.
3. Agar bisa dipasang seperti aplikasi: unggah seluruh isi folder ke hosting HTTPS statis (misalnya GitHub Pages).
4. Buka alamat situs tersebut di Chrome Android > menu titik tiga > Tambahkan ke layar utama / Install app.

PENTING:
- Ini adalah prototipe PWA, belum APK native.
- Tidak ada sistem login, server, saldo, penarikan, atau pembayaran.
- Belum ada iklan aktif. Untuk memperoleh pendapatan iklan, tahap berikutnya adalah membangun APK Android dengan integrasi Google AdMob, menyiapkan kebijakan privasi, dan mengajukan aplikasi untuk peninjauan. Persetujuan dan pendapatan tidak dijamin.
- Jangan menjanjikan pengguna uang atau hadiah dari checklist. Misi di versi ini hanya latihan pribadi.
